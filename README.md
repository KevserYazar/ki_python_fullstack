# KI Python Fullstack – Lernprojekt (Kevser Yazar)

Dieses Repository dokumentiert meinen strukturierten Lernpfad zur **KI- und Backend-Softwareentwicklerin (Python)**.
Fokus: sauberes Engineering, APIs, Datenverarbeitung und später KI-Integration (RAG/Embeddings/Agenten).

## Tech-Stack
- Python 3.12
- FastAPI + Uvicorn
- Git/GitHub
- (später) PostgreSQL/Supabase, OpenAI API, LangChain/LlamaIndex

## Projektstruktur
- `main.py` – Einstieg/Tests einzelner Konzepte
- `api.py` – Mini-API (FastAPI)
- `tag3_datenstrukturen.py` – Listen/Dictionaries/Backend-Denken
- `tag3_aufgabe.py` – Übung Tag 3
- `tag4_saubereCodes.py` – Clean Code, Funktionen, Typen
- `tag4_aufgabe.py` – Übung Tag 4
- `requirements.txt` – Abhängigkeiten
- `tests/` – Tests (wächst im Verlauf)
